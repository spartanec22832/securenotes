# Secure Notes

Secure Notes — Android-приложение для создания и хранения заметок в формате \`.md\` с возможностью защиты конфиденциальных данных.

## Технологический стек

- **Kotlin** — основной язык разработки.
- **Jetpack Compose** — основной фреймворк для UI.
- **Room** — локальная база данных (планируется).
- **Android Keystore, Biometric API** — защита данных и аутентификация (планируется).
- **Gradle (Kotlin DSL)** — система сборки.
- **Java 17**

## Проверка корректности сборки

Проверь корректность сборки:
```cmd
.\gradlew.bat clean assembleDebug
```

## Git Flow

Для командной разработки используется упрощённый Git Flow.

`master` — основная защищённая ветка проекта. Разработка ведётся в отдельных ветках, а изменения в `master` вносятся через Pull Request (PR).

### Именование веток

| Префикс                      | Назначение                    |
|------------------------------|-------------------------------|
| `feat/SN-<номер задачи>`     | Фичи                          |
| `fix/SN-<номер задачи>`      | Исправление ошибок            |
| `style/SN-<номер задачи>`    | Изменения оформления и UI     |
| `refactor/SN-<номер задачи>` | Рефакторинг кода              |
| `docs/SN-<номер задачи>`     | Изменения документации        |
| `test/SN-<номер задачи>`     | Добавление и изменение тестов |
| `chore/SN-<номер задачи>`    | Конфигурация проекта          |
| `ci/SN-<номер задачи>`       | Настройка CI/CD               |

Именование ветки вида: `<префикс>/SN-<номер задачи>`

Именование коммита вида: `<префикс> SN-<номер задачи>: <текст коммита>`

Это необходимо для того, чтобы Jira подхватывала коммиты

### Правила командной работы

- Не выполнять прямой push в `master`.
- Force push в `master` запрещён.
- Каждая задача разрабатывается в отдельной ветке.
- Перед созданием PR необходимо убедиться, что проект собирается, а изменения не нарушают существующую функциональность.
- Для слияния изменений используется Pull Request с проверкой кода.
- При необходимости рабочая ветка синхронизируется с актуальным `master`.
